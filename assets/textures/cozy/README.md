# Textura pintada

`painted_limestone.png` foi gerada para este projeto pela ferramenta integrada `image_gen`. É usada no shader `psx_pro.gdshader` para superfícies de pedra de tipo 8. O arquivo original é preservado; a importação do Godot limita a textura a 512 px e gera mipmaps para reduzir cintilação à distância.

Prompt completo usado:

Create a production game environment diffuse albedo texture, square, seamless tileable on all four edges. Straight orthographic top-down view, completely flat lighting. Cozy hand-painted PS1 fantasy garden cobblestone paving, evoking the painted storybook richness of Legend of Mana. Approximately 6 by 6 irregular rounded rectangular warm ivory limestone pavers, subtly different sizes, restrained ochre and muted rose variations, thin earthy mortar and occasional muted sage moss tucked into cracks. Each stone has hand-painted broad soft brush variation and subtle edge wear, very gentle contact shading painted at seams only. Readable large shapes at 128px. No perspective, no objects, no plants sticking out, no deep shadows, no directional sunlight, no labels, no border, no watermark. Full image is usable texture, not a texture preview sphere or scene. Color overall medium warm sandstone, not washed-out white, not photorealistic. The opposite edges must tile as a continuous paved surface.
